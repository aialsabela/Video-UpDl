# دانلود فایل از تلگرام با GitHub Actions

این ریپو با اجرای یک GitHub Action، فایل مورد نظر شما را از یک پیام تلگرام
دانلود کرده و به‌صورت **GitHub Release** در دسترستان قرار می‌دهد
(لینک دانلود مستقیم، مناسب فایل‌های حجیم).

## پیش‌نیازها (فقط یک‌بار)

### ۱. گرفتن API_ID و API_HASH
1. به [my.telegram.org](https://my.telegram.org) بروید و با شماره تلگرام‌تان وارد شوید.
2. به بخش **API development tools** بروید.
3. یک اپلیکیشن جدید بسازید و مقادیر `api_id` و `api_hash` را یادداشت کنید.

### ۲. ساخت Session String
1. روی سیستم خودتان (نه گیت‌هاب):
   ```
   pip install telethon
   python scripts/generate_session.py
   ```
2. شماره تلفن، کد تایید و (در صورت فعال بودن) رمز دو مرحله‌ای را وارد کنید.
3. رشته‌ای طولانی چاپ می‌شود؛ آن را کپی کنید (این رشته معادل ورود به اکانت شماست، جایی منتشرش نکنید).

### ۳. ثبت Secrets در گیت‌هاب
در ریپو بروید به:
`Settings → Secrets and variables → Actions → New repository secret`

چهار Secret زیر را بسازید:

| نام Secret            | مقدار                                                        |
|------------------------|---------------------------------------------------------------|
| `TELEGRAM_API_ID`      | همان api_id از مرحله ۱                                        |
| `TELEGRAM_API_HASH`    | همان api_hash از مرحله ۱                                      |
| `TELEGRAM_SESSION`     | رشته‌ای که از مرحله ۲ گرفتید                                   |
| `TELEGRAM_CHANNEL_ID`  | آیدی عددی کانال/گروه (مثلاً `-1001234567890`) یا username آن  |

> `TELEGRAM_CHANNEL_ID` اختیاریه؛ فقط وقتی لازمه که بخواید در ورودی workflow
> صرفاً آیدی عددی پیام رو بدید (بدون لینک کامل).

## استفاده

1. به تب **Actions** ریپو بروید.
2. workflow با نام **Download from Telegram** را انتخاب کنید.
3. روی **Run workflow** بزنید.
4. یکی از این دو حالت را در ورودی `message_link` وارد کنید:
   - فقط آیدی عددی پیام، مثلاً `123` (نیازمند تنظیم `TELEGRAM_CHANNEL_ID`)
   - لینک کامل پیام:
     - کانال/گروه عمومی: `https://t.me/channelname/123`
     - کانال/گروه خصوصی: `https://t.me/c/1234567890/123`
       (این لینک را با راست‌کلیک روی پیام در اپ تلگرام دسکتاپ → Copy Message Link می‌گیرید)
5. اکشن اجرا می‌شود، فایل را دانلود می‌کند و به‌صورت خودکار یک **Release** جدید
   با همان فایل می‌سازد.
6. بعد از پایان اکشن، به تب **Releases** ریپو بروید و فایل را دانلود کنید.

## نکات مهم

- چون از اکانت شخصی (Telethon) استفاده می‌شود، محدودیت حجم فایل تلگرام
  (حدود ۲ گیگابایت برای اکانت‌های عادی) اعمال می‌شود، نه محدودیت ۲۰ مگابایتی بات‌ها.
- گیت‌هاب هم برای هر فایل در Release محدودیت ۲ گیگابایت دارد.
- اجرای هر Action معمولاً حداکثر ۶ ساعت زمان دارد؛ برای فایل‌های خیلی حجیم
  ممکن است دانلود کامل نشود.
- `TELEGRAM_SESSION` معادل رمز عبور اکانت تلگرام شماست؛ آن را فقط به‌صورت Secret
  نگه دارید و هرگز داخل کد یا commit قرار ندهید.

## حالت خودکار: فقط فایل رو به بات بفرست

با این روش، هر فایلی که به یک بات تلگرام بفرستید، خودکار دانلود و در قالب
یک Release گیت‌هاب منتشر می‌شود، و در پایان لینک Release برایتان روی تلگرام
ارسال می‌شود. معماری: **بات تلگرام → Cloudflare Worker (وب‌هوک) → GitHub Action**

### ۱. ساخت بات تلگرام
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید.
2. دستور `/newbot` را بزنید و اسم و username دلخواه برای بات انتخاب کنید.
3. یک توکن به شکل `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` می‌گیرید؛ آن را نگه دارید.

### ۲. ساخت GitHub Personal Access Token
1. به `github.com/settings/tokens` بروید → **Generate new token (classic)**
2. فقط اسکوپ `repo` را تیک بزنید.
3. توکن را کپی کنید (فقط یک‌بار نشان داده می‌شود).

### ۳. دیپلوی Cloudflare Worker
1. در [dash.cloudflare.com](https://dash.cloudflare.com) یک اکانت رایگان بسازید (نیاز به کارت بانکی ندارد).
2. از منو: **Workers & Pages → Create → Create Worker**
3. یک اسم بدهید (مثلاً `telegram-downloader`) و **Deploy** بزنید.
4. روی **Edit code** بزنید و کل محتوای فایل `cloudflare-worker/worker.js` این ریپو
   را جایگزین کد پیش‌فرض کنید، سپس **Deploy** بزنید.
5. به تب **Settings → Variables and Secrets** ورکر بروید و این مقادیر را
   به‌صورت **Secret** اضافه کنید:

   | نام متغیر                 | مقدار                                  |
   |----------------------------|------------------------------------------|
   | `TELEGRAM_BOT_TOKEN`       | توکن بات از مرحله ۱                      |
   | `GITHUB_TOKEN`              | Personal Access Token از مرحله ۲         |
   | `GITHUB_OWNER`               | نام کاربری گیت‌هاب شما                   |
   | `GITHUB_REPO`                 | اسم ریپو (مثلاً `Video-UpDl`)             |
   | `TELEGRAM_WEBHOOK_SECRET`     | یک رشته دلخواه و تصادفی (برای امنیت)     |

6. آدرس ورکر شما چیزی شبیه این است:
   `https://telegram-downloader.YOUR-SUBDOMAIN.workers.dev`

### ۴. وصل کردن وب‌هوک بات به ورکر
در مرورگر یا ترمینال (یا یک سلول کولب)، این آدرس را باز کنید
(مقادیر داخل `< >` را جایگزین کنید):

```
https://api.telegram.org/bot<TOKEN_BAT>/setWebhook?url=<آدرس_ورکر>&secret_token=<همون TELEGRAM_WEBHOOK_SECRET>
```

اگر پاسخ `{"ok":true,...}` گرفتید، وب‌هوک با موفقیت وصل شده است.

### ۵. اضافه کردن Secret جدید در گیت‌هاب
یک Secret دیگر هم به ریپو اضافه کنید (علاوه‌بر ۴ تای قبلی):

| نام Secret            | مقدار                                                            |
|------------------------|--------------------------------------------------------------------|
| `TELEGRAM_BOT_TOKEN`   | همان توکن بات (برای اینکه Action بتواند پیام تایید برایتان بفرستد) |

و مقدار Secret `TELEGRAM_CHANNEL_ID` را به **username بات** (بدون `@`) تغییر دهید،
چون در این حالت فایل همیشه از چت شما با بات خوانده می‌شود، نه یک کانال دیگر.

### ۶. استفاده
فقط کافیست فایل (ویدیو، سند یا صوت) را مستقیم برای بات بفرستید. بات بلافاصله
پیام تاییدی می‌فرستد، Action در گیت‌هاب اجرا می‌شود، و در پایان لینک Release
همان‌جا روی تلگرام برایتان ارسال می‌شود. شما فقط لینک را باز، فایل را دانلود،
و در صورت تمایل Release را پاک می‌کنید.

> توجه: چون از اکانت شخصی (Telethon) برای خواندن پیام استفاده می‌شود، باید
> همان اکانتی که Session String آن را ساختید، خودش با بات چت کرده و پیام را
> فرستاده باشد (چون Telethon فقط به چت‌هایی دسترسی دارد که آن اکانت عضوشان است).
